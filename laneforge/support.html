Lane Forge — Support

Offline fortress siege defense. Completely free — no ads, no purchases.

Get help

  1. In-app: Home → Settings (mute, volumes, language, reset progress)
  2. GitHub Issues: github.com/wjeanvilma/laneforge/issues — include device, OS, app version from Settings → About, and steps to reproduce.

Common fixes

ProblemTry this
Progress missing after reinstall Saves are local only; reinstall clears them unless the device was backed up
No sound Settings → unmute; raise Music / Sound effects
Want a clean start Settings → Reset progress
